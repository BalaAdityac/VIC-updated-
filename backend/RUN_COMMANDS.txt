VIC RECRUITER WORKFLOW - STABILIZATION COMMANDS

1. Install dependencies
npm install

2. Validate Prisma
npx prisma validate
npx prisma generate

3. Check migration state
npx prisma migrate status

4. Apply the recruiter workflow + stabilization migrations
npx prisma migrate dev

5. Start API
npm run dev

6. Run real database integration tests in another PowerShell terminal
node scripts/integration-test.js

Expected:
ALL INTEGRATION TESTS PASSED

7. Import Postman collection
postman/VIC-Recruiter-Workflow.postman_collection.json

GET /api/student/applications
GET /api/student/interviews

POST /api/company/internships
